# 配管設計ノート

水配管の経路入力、配管径・圧力損失・ポンプ能力の概算、配管図のPDF・DXF出力を行うブラウザーアプリです。WindowsのMicrosoft EdgeまたはGoogle Chromeを想定しています。設計流量は **m³/min** で入力します。

> **試作版・設計検討用**：計算値と図面は、設計者が前提条件、実製品、各社基準、使用条件に照らして検証してください。現時点では、調達・製作・施工用の最終成果物として、そのまま使用できません。下記の「適用範囲と未評価」も確認してください。

## 起動方法

**[配管設計ノートを開く](https://meganezaru1096-hue.github.io/piping-design-notebook/)** をEdgeまたはChromeで開きます。会社で利用する場合は、このURLを共有してください。

ファイルを手元で使用する場合は、このリポジトリをZIPでダウンロード・展開し、`index.html` をEdgeまたはChromeで開きます。追加インストールは不要です。HTMLと同じフォルダーにあるJavaScript・CSSファイルを移動しないでください。画面上部から「開放系」と「密閉循環・冷却水」を切り替えられます。

## はじめ方

1. 開放系は `index.html`、冷却水などの密閉循環系は `circulation.html` を開きます。
2. 共通条件と設備ごとの設計流量・必要圧力または圧力損失を入力します。
3. 配管区間を始点から、東・西・南・北・上・下と長さ（m）で追加します。斜め区間はX・Y・Zの移動量で指定します。既存点から枝を追加できます。
4. 区間内のバルブ・損失係数や接続点の継手を登録し、表示された要確認事項を確認します。継手の損失は自動で追加されません。
5. 計算結果を確認し、入力は「保存 JSON」で保存します。次回は「読込 JSON」で再開できます。下書きは使用したブラウザーの保存領域に残るため、共有PCでは利用者と管理方法に注意してください。
6. 図面欄からアイソメ図・三面図のDXF、図面のPDFを出力できます。Jw_cadで開く場合はDXFの文字形式で「Jw_cad向け」を選択してください。

[複雑な循環配管の入力例](サンプル/図面_注記整理/注記整理_サンプル.json)を「読込 JSON」で読み込めます。数値や部品は評価用の仮値です。[評価PDF](サンプル/図面_注記整理/注記整理_図面と計算.pdf)とJw_cad用DXFも同じフォルダーにあります。

## 材料・施工の概算金額

「概算金額」欄で、配管径別の中心線長、登録したバルブ、選択済み継手、ポンプ・設備などに、材料単価と施工単価を入力します。単価は税抜・円／表示単位です。空欄は未入力、0はゼロ円として扱います。未入力の単価がある場合、表示額は入力済み分の小計です。対象外項目はチェックを外し、支持材・保温・試験などは手入力で追加できます。入力単価・根拠・対象外の指定はプロジェクトJSONに保存します。「概算金額 PDF」で明細を出力できます。

配管の数量は折れ点間の中心線長で、継手控除・切断長・定尺・歩留まりは未反映です。未選択の継手や損失計算のみの継手は自動集計しません。ボルト・溶接材・支持・保温・塗装・検査・運搬・諸経費などの抜けや単価の適用範囲を別途確認してください。消費税は含みません。[評価サンプル](サンプル/概算金額/概算金額_サンプル.json)の単価は表示確認用の仮値で、市場価格ではありません。

## 適用範囲と未評価

- 開放系はポンプ1台からの分岐、密閉循環系はポンプ1台・往きの分岐・戻りの再合流を対象とします。入力した設備は同時運転する設計上の仮定です。網目状の任意再合流、複数ポンプ、開放冷却塔は対象外です。
- ポンプ運転点と並列枝の流量は、入力した曲線やKv比、圧損の二乗則を前提とする近似です。実機の性能曲線、制御特性、運転範囲と一致する保証はありません。
- 静水圧とNPSHは指定した条件に基づく個別の概算です。運転時の圧力分布、吸込経路の自動評価、膨張タンク容量、空気抜き、水撃、耐圧や材料の適合は未評価です。
- 配管径の候補は流速と任意の直管圧損勾配によるものです。継手やバルブのK値、メーカー条件、圧力等級、肉厚、腐食代などは別途確認が必要です。
- 図面は配管外径と一部継手の参考寸法を反映した**2D概略図**です。点間寸法は管の切断長ではありません。機器・バルブの一部は模式表示で、実機寸法、支持、干渉、溶接、隠線、施工空間、製図規格への適合は別途確認が必要です。
- DXFの注記配置は近似計算です。CADで文字、引出線、線種、単位、寸法および印刷を確認してください。Jw_cad向け形式で表せない文字を含む場合は出力時に通知します。

実運用を始める前に、会社の承認手順に沿って基準ケースでの独立計算、使用CADでの実測、メーカー資料との照合を実施してください。

## データの扱い

入力はブラウザー内で処理され、アプリに入力データを送信するサーバー機能はありません。JSON・DXF・PDFはブラウザーのダウンロードとして保存します。GitHub Pagesで配布した場合、アプリのファイルはGitHubから取得されます。機密データを含むJSONや図面は、公開リポジトリにアップロードせず、会社で定めた保存場所で管理してください。

## 開発とテスト

Node.js 22以降で、リポジトリのフォルダーから `npm test` を実行します。アプリの利用にNode.jsは不要です。テスト用のJSONとDXFはリポジトリに含めています。

## フォントとライセンス

PDF出力にはNoto Sans JPを使用します。フォントのライセンスは [NotoSansJP-OFL.txt](NotoSansJP-OFL.txt) を参照してください。アプリケーションのソースコードには、現時点で別途のオープンソースライセンスは設定されていません。再配布・改変・利用の許諾条件は権利者に確認してください。
